# Local Pilot Dataset (Simple Start)

Use this dataset first.

Why:
- easy to understand
- small size
- full control

Files:
- `requirements.csv`
- `code_units.csv`
- `gold_links.csv`

Steps:
1. Fill 10-20 requirement rows in `requirements.csv`.
2. Fill 20-40 code unit rows in `code_units.csv`.
3. Fill true links in `gold_links.csv`.
4. Start pipeline testing.
